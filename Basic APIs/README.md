# Basic APIs

This folder contains notebooks and scripts used for getting familiar with basic LLM and web scraping APIs, and differnet arguments for the APIs.

## Main Project

*   **`brochure_making.ipynb`**: The primary project in this folder. It utilizes LLMs and web scraping to read a company's website and automatically generate a polished, informative brochure based on their content.

## Learning & Exploration

The other files in this folder:

*   **`my_easy_scraper.py`**: A foundational script used to practice extracting text and data from web pages.
*   **`usage_and_API_GPT.ipynb`**: A notebook used to practice OpenAI API and understand its usage.
